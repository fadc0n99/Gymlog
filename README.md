# Дневник тренировок (офлайн PWA)

Статическое веб-приложение: `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icons/`.
Без сборки и зависимостей. Данные хранятся в `localStorage` на устройстве (ключ `gymlog.v1`).

## Публикация на GitHub Pages

1. Создай публичный репозиторий, например `gymlog`.
2. Залей в корень все файлы из архива:
   ```
   git init && git add . && git commit -m "gymlog"
   git branch -M main
   git remote add origin https://github.com/<логин>/gymlog.git
   git push -u origin main
   ```
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через минуту приложение будет по адресу `https://<логин>.github.io/gymlog/`.

## Установка на iPhone

1. Открой ссылку **в Safari** (в других браузерах на iOS установка тоже идёт через «Поделиться», но надёжнее Safari).
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Запусти с иконки один раз при интернете — после этого всё работает без сети.

Важно: данные иконки на экране и данные вкладки Safari — разные хранилища. Пользуйся всегда иконкой.

## Обновление приложения

Поменял файлы → увеличь `CACHE` в `sw.js` (`gymlog-v2` и т. д.) → push.
Приложение отдаёт файлы из кэша мгновенно и в фоне подтягивает новые: новая версия появится со второго запуска.

## Резервная копия

Программа → «Сохранить резервную копию» (JSON через меню «Поделиться» → «Сохранить в Файлы»).
Восстановление — «Восстановить из копии». Если удалить иконку с экрана, данные удалятся вместе с ней.
